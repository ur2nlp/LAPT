# `lapt_core.plotting`

Plot training metrics from a HuggingFace Trainer state, as a CLI or as
importable functions.

The per-project usage examples shown by `--help` come from the calling script's
own module docstring, passed to `main()` as `epilog`.

Requires the `plotting` extra (`pip install "lapt-core[plotting]"`).

::: lapt_core.plotting
